# golden-line skill

The `golden-line` skill describes how to operate this project's instrument: a
versioned aspiration registry, a staged `progress_report` evaluator that returns
one bounded directional reading per aspiration, and a descriptive analysis layer
that characterizes the registry without scoring it.

Read [`SKILL.md`](SKILL.md) for the operating body — decision order, intake
semantics, temporal review, the invariant battery, and the known gotchas.
[`AGENTS.md`](AGENTS.md) records the folder contract.

The package under [`../../../src/golden_line/`](../../../src/golden_line/) is the
source of truth; this folder documents it and adds nothing to it.
