# Release packet — Golden Line 0.6.1 (2026-11-08)

Repository: <https://github.com/docxology/golden_line>. Source tag: `v0.6.1`.
This is a runtime-compatibility correction to the 0.6.0 minor release, not a new
instrument, registry revision, transport schema, or external archival edition.

## Correction

The existing CI matrix includes Python 3.10–3.15. The 0.6.0 package requirement
accidentally excluded Python 3.10, and the release-evidence CLI and datetime
boundary tests imported the Python 3.11-only `datetime.UTC` alias. The actual
[main workflow failure](https://github.com/docxology/golden_line/actions/runs/42470188142)
and [tag workflow failure](https://github.com/docxology/golden_line/actions/runs/42470188112)
are retained; the published `v0.6.0` tag is not moved or replaced.

The package again supports Python 3.10. Release evidence uses `timezone.utc`
with the same timezone-aware ISO timestamp representation. The locked development
environment covers the existing interpreter range. Runtime dependencies remain
standard-library-only. Evaluation precedence, admission, registry vocabulary,
registry revision, and archive/envelope wire formats are unchanged.

Source-wiring and prose-wording assertions are removed rather than repinned.
Real local-link closure, bibliography closure, datetime rejection, evaluator,
archive, and evidence failure controls remain behavioral checks.

## Verification and custody

The existing workflow, interpreter matrix, full native gate surface, and 90%
coverage floor are unchanged. `golden_line.release_evidence` records the actual
committed source, runtime, source-byte stability, complete gate results, registry,
and artifact identities; a failed or partial gate cannot pass.

Configured PDF, HTML, and EPUB rendering is separate from native gate evidence.
Each new rendered receipt must identify its real producer source; an older 0.6.0
receipt or pinned family snapshot is not relabeled as 0.6.1 evidence. Historical
release packets, report fixtures, and DOI metadata retain their original scope.
The last verified Zenodo edition remains 0.4.1. This source release does not mint
a DOI or publish a GitHub Release, PyPI package, or external archival deposit.
