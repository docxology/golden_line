# Retained noncanonical manuscript

`02a_formalism.md` is the byte-preserved legacy file formerly at
`manuscript/02a_formalism.md`. It is historical source, not the current evaluator
contract. The maintained manuscript is `docs/manuscript/`.

The legacy file lives outside the renderer's manuscript discovery roots so it
cannot shadow the configured current manuscript during a standalone render.
Its original wording and measurements are preserved rather than updated to
look like current evidence.
