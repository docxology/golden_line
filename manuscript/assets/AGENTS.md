# Golden Line manuscript asset guidance

The project-level `AGENTS.md` remains authoritative. This folder contains
publication assets, not evaluator evidence.

- Preserve the cover's RGB, text-free, full-frame character and keep its visual
  rationale in `README.md`.
- Do not add claims, status labels, or generated figures to the cover asset.
- Keep manuscript configuration references relative to `manuscript/` and run
  the rendered title-page check after changing the cover.
